# Install the profile

This package is designed for the special profile repository `phuocdevvn/phuocdevvn`.

1. Download and extract the ZIP archive.
2. Open the extracted `phuocdevvn-profile-clean` folder.
3. Replace the repository's `README.md` with the included `README.md`.
4. Remove the old files under `assets/` that this README no longer uses: `ASSETS.md`, `animations/`, `banner/`, `decor/`, `icons/`, and `projects/`.
5. Upload the new `assets/` folder from this package. It contains `banner.svg`, `stack.svg`, `terminal.gif`, and `footer.svg`.
6. Keep the paths and file names unchanged; the README uses relative paths such as `assets/banner.svg`.
7. Commit the changes and refresh your GitHub profile.

The profile uses local SVG/GIF assets only. It does not depend on remote badge services, animated-statistics services, or external icon packs.
